Installeer je eigen Orqevio

Kies waar het draait: in je Cloudflare-account, met een opdracht of een knop, of op je eigen server met Docker. In alle drie de gevallen is de installatie van jou en werkt alles hetzelfde.

Met een opdracht Aanbevolen

Je installatie komt in je eigen Cloudflare-account: een Worker met de webapp, de API en MCP, een SQLite-database en een R2-bucket voor bijlagen.

Wat je nodig hebt: een Cloudflare-account (het gratis abonnement is genoeg) en Node.js 22.12 of nieuwer.

Schakel eerst R2 in in het Cloudflare-dashboard, onder R2 → Overview. Het inbegrepen gebruik is gratis (10 GB opslag per maand), al kan Cloudflare om een betaalmethode vragen. Beide manieren om op Cloudflare te installeren hebben het nodig: de opdracht en de knop.

$ npx create-orqevio
  1. Je browser opent, zodat je kunt inloggen bij Cloudflare.
  2. Je kiest een naam voor de installatie (standaard orqevio), die onderdeel wordt van het adres.
  3. De installer rolt de installatie uit en maakt de bucket aan.
  4. Je krijgt het adres te zien (https://orqevio.<jouw-subdomein>.workers.dev) en een eenmalige installatiecode.

Open het adres en volg de stappen bij eerste keer inloggen.

  • Meerdere installaties: voeg --name <naam> toe aan een opdracht.
  • Meerdere Cloudflare-accounts: de installer vraagt welk account je wilt gebruiken, of je geeft het op met --account <id>.
  • Opent de browser niet om in te loggen, open dan de link die de installer toont. Werkt dat ook niet, log dan apart in met npx wrangler login --browser=false en voer de installer opnieuw uit.
  • Taal: de installer spreekt de taal van je terminal; kies een andere met --lang <code>.
  • Privacy: de installer zet de telemetrie van Wrangler uit, tenzij je die zelf hebt aangezet, en werkt in een tijdelijke map die hij na afloop verwijdert.

Met de knop

Bewaar je je installatie liever in een eigen repository op GitHub of GitLab? Gebruik dan de knop:

Deploy to Cloudflare

Cloudflare maakt een kleine repository aan in je GitHub- of GitLab-account, vraagt je om de installatiecode (SETUP_CODE), die je zelf kiest, en rolt de installatie uit. Daarna:

  • Elke wijziging in die repository wordt automatisch uitgerold.
  • Dependabot stelt nieuwe versies van Orqevio voor in een pull request; zodra je die merget, wordt je installatie bijgewerkt.
  • Ben je je sleutel kwijt, wijzig dan het secret SETUP_CODE in het Cloudflare-dashboard en gebruik ‘Sleutel kwijt?’ op het inlogscherm.

Met Docker op je server

Eén container (voor amd64 en arm64), met de SQLite-database en de bijlagen in een volume. Download de configuratie:

$ curl -fsSLO https://raw.githubusercontent.com/hsylabs/orqevio/main/docker-compose.yml
$ curl -fsSL -o .env https://raw.githubusercontent.com/hsylabs/orqevio/main/.env.example

Bewerk .env: zet in APP_URL het openbare adres van je installatie (bijvoorbeeld https://orqevio.jouw-domein.nl) en, als je wilt, een eigen SETUP_CODE van minstens 12 letters of cijfers. Daarna:

$ docker compose up -d

De installatie luistert op poort 3000. Zet hem achter een reverse proxy met HTTPS (Caddy, Nginx of Traefik) en voeg TRUST_PROXY=true toe aan .env.

Back-ups: kopieer het volume orqevio-data terwijl de installatie is gestopt, of maak een live back-up van de database met sqlite3 en bewaar ook de map uploads.

Eerste keer inloggen

  1. Stel je installatie in. Open het adres en voer de installatiecode en je naam in. Op Cloudflare krijg je de code van de installer; met Docker is het de SETUP_CODE uit .env of, als je er geen hebt ingesteld, de code in het containerlog (docker compose logs app).
  2. Bewaar je toegangssleutel. Orqevio genereert een willekeurige sleutel van 160 bits en toont die maar één keer. Bewaar hem in je wachtwoordmanager: meer heb je niet nodig om vanaf elk apparaat in te loggen.
  3. Ben je hem kwijt, genereer dan een nieuwe code met npx create-orqevio@latest recover (Cloudflare) of docker compose exec app node dist/cli.js reset-access (Docker), en gebruik die bij ‘Sleutel kwijt?’. Je kluis blijft onaangetast: de server kent het hoofdwachtwoord nooit.

Je installatie spreekt de taal die je browser gebruikt op het moment dat je hem instelt: Engels, Spaans, Frans, Portugees, Italiaans, Duits, Nederlands of Japans. Je kunt de taal altijd wijzigen in Instellingen.

Agents koppelen

Het MCP-adres van je installatie is https://<jouw-installatie>/mcp.

  • Claude op web, desktop en mobiel: voeg een aangepaste connector toe met dat adres. Je installatie vraagt je om toestemming op een scherm waar je de werkruimte kiest en bepaalt wat de app mag doen. Je installatie moet via HTTPS bereikbaar zijn vanaf internet; op Cloudflare is dat al zo.
  • Claude Code, Cursor, VS Code en andere: onder Agents → Agent koppelen maak je een token aan en krijg je de configuratie die je moet plakken.

Geen enkele agent kan de kluis lezen, zelfs niet versleuteld, en geen enkele kan iets verwijderen: agents kunnen alleen archiveren, en jij kunt herstellen.

Bijwerken

Je installatie laat je in Instellingen → Deze installatie weten wanneer er een nieuwe versie is, met precies de stap die bij jouw manier van installeren hoort. Je gegevens, je sleutel en je kluis blijven altijd behouden.

InstallatieZo werk je bij
Met een opdrachtnpx create-orqevio@latest update
Met de knopMerge de pull request van Dependabot in je repository
Met Dockerdocker compose pull en docker compose up -d

Verwijderen

Instellingen → Orqevio verwijderen wist alles definitief: werkruimtes, documenten, bijlagen, de kluis en de toegang van je agents. Je bevestigt met je toegangssleutel en door de naam van de installatie te typen. Daarna laat de installatie zien hoe je de rest weghaalt:

InstallatieZo haal je de rest weg
Met een opdrachtnpx create-orqevio@latest uninstall verwijdert de Worker en de bucket. Het kan ook alles in één keer, zonder Instellingen: het vraagt het adres van je installatie om die eerst te legen
Met de knopDe Worker en de R2-bucket, in het Cloudflare-dashboard; daarna de repository die de knop maakte
Met Dockerdocker compose down -v, en daarna de map waarin je hem installeerde

Kosten

Orqevio kost niets. Met Docker betaal je voor je server. Op Cloudflare is het gratis abonnement genoeg voor persoonlijk gebruik:

OnderdeelGratis abonnement
Verzoeken100.000 per dag
CPU10 ms per verzoek; bij normaal gebruik blijft het op 1–5 ms
Database1 GB per installatie
Bijlagen (R2)10 GB en 1 miljoen schrijfbewerkingen per maand

Limieten per november 2026. Bekijk de actuele limieten in de documentatie van Cloudflare.
