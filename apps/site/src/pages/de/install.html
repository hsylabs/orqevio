Installationsanleitung

Installiere deine Instanz

Du entscheidest, wo sie läuft: in deinem Cloudflare-Konto, per Befehl oder per Button, oder mit Docker auf deinem Server. In allen drei Fällen gehört die Instanz dir und funktioniert genau gleich.

Per Befehl Empfohlen

Deine Instanz wird in deinem eigenen Cloudflare-Konto installiert: ein Worker mit der Web-App, der API und dem MCP-Server, eine SQLite-Datenbank und ein R2-Bucket für Anhänge.

Du brauchst ein Cloudflare-Konto (der kostenlose Plan reicht aus) und Node.js 22.12 oder neuer.

Aktiviere vorher R2 im Cloudflare-Dashboard unter R2 → Overview. Die enthaltene Nutzung ist kostenlos (10 GB Speicherplatz pro Monat), Cloudflare fragt aber eventuell nach einer Zahlungsmethode. Beide Wege, Orqevio bei Cloudflare zu installieren, setzen R2 voraus: der Befehl und der Button.

$ npx create-orqevio
  1. Dein Browser öffnet sich, damit du dich bei Cloudflare anmelden kannst.
  2. Du wählst einen Namen für die Instanz (standardmäßig orqevio), der Teil ihrer Adresse wird.
  3. Der Installer stellt die Instanz bereit und legt ihren Bucket an.
  4. Zum Schluss zeigt er dir die Adresse (https://orqevio.<deine-subdomain>.workers.dev) und einen einmaligen Einrichtungscode.

Öffne die Adresse und folge den Schritten unter Erste Anmeldung.

  • Mehrere Instanzen: Hänge --name <name> an einen beliebigen Befehl an.
  • Mehrere Cloudflare-Konten: Der Installer fragt, welches er verwenden soll, oder du gibst es mit --account <id> an.
  • Falls sich der Browser nicht öffnet, um dich anzumelden, öffne den Link, den der Installer anzeigt. Klappt auch das nicht, melde dich separat mit npx wrangler login --browser=false an und starte den Installer erneut.
  • Sprache: Der Installer spricht die Sprache deines Terminals; eine andere wählst du mit --lang <code>.
  • Datenschutz: Der Installer schaltet die Telemetrie von Wrangler ab, sofern du sie nicht selbst aktiviert hast, und arbeitet in einem temporären Ordner, den er am Ende löscht.

Per Button

Wenn du deine Instanz lieber in einem eigenen Repository auf GitHub oder GitLab verwalten möchtest:

Deploy to Cloudflare

Cloudflare legt ein kleines Repository in deinem GitHub- oder GitLab-Konto an, fragt dich nach dem Einrichtungscode (SETUP_CODE), den du selbst wählst, und stellt die Instanz bereit. Danach gilt:

  • Jede Änderung in diesem Repository wird automatisch bereitgestellt.
  • Dependabot schlägt neue Orqevio-Versionen als Pull-Request vor; sobald du ihn mergst, wird deine Instanz aktualisiert.
  • Wenn du deinen Schlüssel verlierst, ändere das Secret SETUP_CODE im Cloudflare-Dashboard und nutze „Schlüssel verloren?“ auf dem Anmeldebildschirm.

Mit Docker auf deinem Server

Ein einzelner Container (für amd64 und arm64), dessen SQLite-Datenbank und Anhänge in einem Volume liegen. Lade die Konfiguration herunter:

$ curl -fsSLO https://raw.githubusercontent.com/hsylabs/orqevio/main/docker-compose.yml
$ curl -fsSL -o .env https://raw.githubusercontent.com/hsylabs/orqevio/main/.env.example

Bearbeite die .env: Trage unter APP_URL die öffentliche Adresse deiner Instanz ein (zum Beispiel https://orqevio.deine-domain.de) und, wenn du möchtest, einen eigenen SETUP_CODE mit mindestens 12 Buchstaben oder Ziffern. Dann:

$ docker compose up -d

Die Instanz lauscht auf Port 3000. Betreibe sie hinter einem Reverse Proxy mit HTTPS (Caddy, Nginx oder Traefik) und ergänze TRUST_PROXY=true in der .env.

Backups: Kopiere das Volume orqevio-data, während die Instanz gestoppt ist, oder erstelle mit sqlite3 ein Live-Backup der Datenbank und sichere zusätzlich den Ordner uploads.

Erste Anmeldung

  1. Richte deine Instanz ein. Öffne ihre Adresse und gib den Einrichtungscode und deinen Namen ein. Bei Cloudflare bekommst du den Code vom Installer; mit Docker ist es der SETUP_CODE aus der .env oder, falls du keinen festgelegt hast, der Code aus dem Container-Log (docker compose logs app).
  2. Speichere deinen Zugangsschlüssel. Orqevio erzeugt einen zufälligen 160-Bit-Schlüssel und zeigt ihn nur einmal an. Speichere ihn in deinem Passwort-Manager: Mehr brauchst du nicht, um dich auf jedem Gerät anzumelden.
  3. Wenn du ihn verlierst, erzeuge einen neuen Code mit npx create-orqevio@latest recover (Cloudflare) oder docker compose exec app node dist/cli.js reset-access (Docker) und gib ihn unter „Schlüssel verloren?“ ein. Dein Tresor ist davon nicht betroffen: Der Server kennt sein Master-Passwort nie.

Deine Instanz übernimmt beim Einrichten die Sprache deines Browsers: Englisch, Spanisch, Französisch, Portugiesisch, Italienisch, Deutsch, Niederländisch oder Japanisch. Du kannst sie jederzeit unter Einstellungen ändern.

Agenten verbinden

Die MCP-Adresse deiner Instanz lautet https://<deine-instanz>/mcp.

  • Claude im Web, auf dem Desktop und mobil: Füge einen benutzerdefinierten Konnektor mit dieser Adresse hinzu. Deine Instanz fragt dich dann auf einer eigenen Seite um Erlaubnis; dort wählst du den Arbeitsbereich und legst fest, was der Agent darf. Dafür muss deine Instanz über HTTPS aus dem Internet erreichbar sein; bei Cloudflare ist sie das bereits.
  • Claude Code, Cursor, VS Code und andere: Unter Agenten → Agenten verbinden erstellst du ein Token, und die App gibt dir die passende Konfiguration zum Einfügen.

Kein Agent kann den Tresor lesen, nicht einmal verschlüsselt, und keiner kann etwas löschen: Agenten können nur archivieren, und du kannst alles wiederherstellen.

Aktualisieren

Wenn es eine neue Version gibt, zeigt dir deine Instanz das unter Einstellungen → Diese Instanz an, samt dem genauen Schritt für deine Installation. Deine Daten, dein Schlüssel und dein Tresor bleiben immer erhalten.

InstallationSo aktualisierst du
Per Befehlnpx create-orqevio@latest update
Per ButtonMerge den Dependabot-Pull-Request in deinem Repository
Mit Dockerdocker compose pull und docker compose up -d

Kosten

Orqevio selbst kostet nichts. Mit Docker zahlst du für deinen Server. Bei Cloudflare reicht der kostenlose Plan für die private Nutzung:

RessourceKostenloser Plan
Anfragen100.000 pro Tag
CPU10 ms pro Anfrage; normale Nutzung liegt bei 1–5 ms
Datenbank1 GB pro Instanz
Anhänge (R2)10 GB und 1 Million Schreibvorgänge pro Monat

Stand der Limits: November 2026. Die aktuellen Werte findest du in der Dokumentation von Cloudflare.
