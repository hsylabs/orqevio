Guide d’installation

Installez votre copie

Choisissez où l’héberger : sur votre compte Cloudflare, avec une commande ou un bouton, ou sur votre serveur avec Docker. Dans les trois cas, la copie vous appartient et fonctionne de la même façon.

Avec une commande Recommandé

Votre copie s’installe sur votre propre compte Cloudflare : un Worker avec l’application web, l’API et le serveur MCP, une base de données SQLite et un bucket R2 pour les pièces jointes.

Il vous faut un compte Cloudflare (l’offre gratuite suffit) et Node.js 22.12 ou une version plus récente.

Avant de commencer, activez R2 dans le tableau de bord Cloudflare, sous R2 → Overview. L’utilisation incluse est gratuite (10 Go de stockage par mois), même si Cloudflare peut vous demander un moyen de paiement. Les deux méthodes d’installation sur Cloudflare en ont besoin : la commande comme le bouton.

$ npx create-orqevio
  1. Votre navigateur s’ouvre pour que vous vous connectiez à Cloudflare.
  2. Vous choisissez un nom pour la copie (orqevio par défaut), qui fera partie de son adresse.
  3. L’installateur déploie la copie et crée son bucket.
  4. Il vous affiche l’adresse (https://orqevio.<votre-sous-domaine>.workers.dev) et un code de configuration à usage unique.

Ouvrez l’adresse et suivez les étapes de la première connexion.

  • Plusieurs copies : ajoutez --name <nom> à n’importe quelle commande.
  • Plusieurs comptes Cloudflare : l’installateur vous demande lequel utiliser, ou indiquez-le avec --account <id>.
  • Si le navigateur ne s’ouvre pas pour la connexion, ouvrez le lien affiché par l’installateur. Si cela ne fonctionne toujours pas, connectez-vous séparément avec npx wrangler login --browser=false, puis relancez l’installateur.
  • Langue : l’installateur parle la langue de votre terminal ; choisissez-en une autre avec --lang <code>.
  • Confidentialité : l’installateur désactive la télémétrie de Wrangler, sauf si vous l’avez activée vous-même, et travaille dans un dossier temporaire qu’il supprime une fois terminé.

Avec le bouton

Si vous préférez garder votre copie dans votre propre dépôt GitHub ou GitLab :

Deploy to Cloudflare

Cloudflare crée un petit dépôt sur votre compte GitHub ou GitLab, vous demande le code de configuration (SETUP_CODE), que vous choisissez vous-même, puis déploie la copie. Ensuite :

  • Chaque modification de ce dépôt est déployée automatiquement.
  • Dependabot vous propose les nouvelles versions d’Orqevio dans une pull request ; il suffit de la fusionner pour mettre votre copie à jour.
  • Si vous perdez votre clé, modifiez le secret SETUP_CODE dans le tableau de bord Cloudflare et utilisez « Clé perdue ? » sur l’écran de connexion.

Avec Docker sur votre serveur

Un seul conteneur (pour amd64 et arm64), avec sa base de données SQLite et les pièces jointes dans un volume. Téléchargez la configuration :

$ curl -fsSLO https://raw.githubusercontent.com/hsylabs/orqevio/main/docker-compose.yml
$ curl -fsSL -o .env https://raw.githubusercontent.com/hsylabs/orqevio/main/.env.example

Modifiez .env : indiquez dans APP_URL l’adresse publique de votre copie (par exemple https://orqevio.votre-domaine.com) et, si vous le souhaitez, un SETUP_CODE de votre choix d’au moins 12 lettres ou chiffres. Ensuite :

$ docker compose up -d

La copie écoute sur le port 3000. Placez-la derrière un proxy inverse en HTTPS (Caddy, Nginx ou Traefik) et ajoutez TRUST_PROXY=true à .env.

Sauvegardes : copiez le volume orqevio-data une fois la copie arrêtée, ou faites une sauvegarde à chaud de la base de données avec sqlite3 en conservant aussi le dossier uploads.

Première connexion

  1. Prenez possession de votre copie. Ouvrez son adresse et saisissez le code de configuration et votre nom. Sur Cloudflare, c’est l’installateur qui vous le donne ; avec Docker, c’est le SETUP_CODE de .env ou, si vous n’en avez pas défini, celui qui figure dans le journal du conteneur (docker compose logs app).
  2. Enregistrez votre clé d’accès. Orqevio génère une clé aléatoire de 160 bits et ne l’affiche qu’une seule fois. Enregistrez-la dans votre gestionnaire de mots de passe : elle suffit pour vous connecter depuis n’importe quel appareil.
  3. Si vous la perdez, générez un nouveau code avec npx create-orqevio@latest recover (Cloudflare) ou docker compose exec app node dist/cli.js reset-access (Docker), puis utilisez-le dans « Clé perdue ? ». Votre coffre-fort n’est pas concerné : le serveur ne connaît jamais son mot de passe principal.

Votre copie adopte la langue de votre navigateur au moment où vous en prenez possession : anglais, espagnol, français, portugais, italien, allemand, néerlandais ou japonais. Vous pouvez la changer à tout moment dans Paramètres.

Connecter des agents

L’adresse MCP de votre copie est https://<votre-copie>/mcp.

  • Claude sur le web, sur ordinateur et sur mobile : ajoutez un connecteur personnalisé avec cette adresse. Votre copie vous demande votre autorisation sur un écran où vous choisissez l’espace et ce que Claude a le droit d’y faire. Votre copie doit être accessible en HTTPS depuis Internet ; sur Cloudflare, c’est déjà le cas.
  • Claude Code, Cursor, VS Code et les autres : dans Agents → Connecter un agent, vous créez un jeton et l’application vous donne la configuration à coller.

Aucun agent ne peut lire le coffre-fort, même chiffré, ni rien supprimer : ils peuvent seulement archiver, et vous pouvez restaurer.

Mettre à jour

Votre copie vous prévient dans Paramètres → Cette copie quand une nouvelle version est disponible, avec la marche à suivre exacte pour votre installation. Vos données, votre clé et votre coffre-fort sont toujours conservés.

InstallationComment mettre à jour
Avec une commandenpx create-orqevio@latest update
Avec le boutonFusionnez la pull request de Dependabot dans votre dépôt
Avec Dockerdocker compose pull puis docker compose up -d

Désinstaller

Paramètres → Désinstaller Orqevio supprime tout définitivement : espaces, documents, pièces jointes, coffre-fort et accès de vos agents. Vous confirmez avec votre clé d’accès et en saisissant le nom de la copie. La copie vous montre ensuite comment retirer ce qui reste :

InstallationComment retirer le reste
Avec une commandenpx create-orqevio@latest uninstall supprime le Worker et son bucket. Elle peut aussi tout faire d’un coup, sans passer par Paramètres : elle vous demande la clé d’accès pour vider d’abord la copie
Avec le boutonLe Worker et son bucket R2, dans le tableau de bord Cloudflare, puis le dépôt créé par le bouton
Avec Dockerdocker compose down -v, puis le dossier où vous l’avez installée

Coûts

Orqevio ne coûte rien. Avec Docker, vous payez votre serveur. Sur Cloudflare, l’offre gratuite suffit pour un usage personnel :

RessourceOffre gratuite
Requêtes100 000 par jour
CPU10 ms par requête ; un usage normal reste entre 1 et 5 ms
Base de données1 Go par copie
Pièces jointes (R2)10 Go et 1 million d’écritures par mois

Limites en vigueur en novembre 2026. Consultez les limites actuelles dans la documentation de Cloudflare.
