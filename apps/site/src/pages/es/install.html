Con un comando Recomendada

Tu copia se instala en tu propia cuenta de Cloudflare: un Worker con la web, la API y el MCP, una base de datos SQLite y un bucket R2 para los adjuntos.

Necesitas una cuenta de Cloudflare (el plan gratuito basta) y Node.js 22.12 o superior.

Antes de empezar, activa R2 en el panel de Cloudflare, en R2 → Overview. El uso incluido es gratis (10 GB de almacenamiento al mes), aunque Cloudflare puede pedirte un método de pago. Lo necesitan las dos formas de instalar en Cloudflare: el comando y el botón.

$ npx create-orqevio
  1. Se abre el navegador para que inicies sesión en Cloudflare.
  2. Eliges un nombre para la copia (por defecto, orqevio), que forma parte de su dirección.
  3. El instalador despliega la copia y crea su bucket.
  4. Te muestra la dirección (https://orqevio.<tu-subdominio>.workers.dev) y un código de configuración de un solo uso.

Abre la dirección y sigue el primer acceso.

  • Varias copias: añade --name <nombre> a cualquier orden.
  • Varias cuentas de Cloudflare: el instalador te pregunta cuál usar, o indícala con --account <id>.
  • Si el navegador no se abre para iniciar sesión, abre el enlace que muestra el instalador. Si tampoco funciona, inicia sesión aparte con npx wrangler login --browser=false y vuelve a ejecutar el instalador.
  • Idioma: el instalador habla el idioma de tu terminal; elige otro con --lang <código>.
  • Privacidad: el instalador desactiva la telemetría de Wrangler, salvo que tú la hayas activado, y trabaja en una carpeta temporal que borra al terminar.

Con el botón

Si prefieres tener tu copia en un repositorio propio de GitHub o GitLab:

Deploy to Cloudflare

Cloudflare crea en tu cuenta de GitHub o GitLab un repositorio pequeño, te pide el código de configuración (SETUP_CODE), que eliges tú, y despliega la copia. Después:

  • Cada cambio en ese repositorio se despliega solo.
  • Dependabot te propone las versiones nuevas de Orqevio en un pull request; al fusionarlo, tu copia se actualiza.
  • Si pierdes la clave, cambia el secreto SETUP_CODE en el panel de Cloudflare y usa «¿Has perdido la clave?» en la pantalla de acceso.

Con Docker en tu servidor

Un único contenedor (para amd64 y arm64) con su base de datos SQLite y los adjuntos en un volumen. Descarga la configuración:

$ curl -fsSLO https://raw.githubusercontent.com/hsylabs/orqevio/main/docker-compose.yml
$ curl -fsSL -o .env https://raw.githubusercontent.com/hsylabs/orqevio/main/.env.example

Edita .env: pon en APP_URL la dirección pública de tu copia (por ejemplo, https://orqevio.tu-dominio.com) y, si quieres, un SETUP_CODE propio de al menos 12 letras o dígitos. Después:

$ docker compose up -d

La copia escucha en el puerto 3000. Ponla detrás de un proxy inverso con HTTPS (Caddy, Nginx o Traefik) y añade TRUST_PROXY=true a .env.

Copias de seguridad: copia el volumen orqevio-data con la copia parada, o haz una copia en caliente de la base de datos con sqlite3 y guarda también la carpeta uploads.

Primer acceso

  1. Reclama tu copia. Abre su dirección y escribe el código de configuración y tu nombre. En Cloudflare te lo da el instalador; con Docker, es el SETUP_CODE de .env o, si no pusiste ninguno, el que aparece en el registro del contenedor (docker compose logs app).
  2. Guarda tu clave de acceso. Orqevio genera una clave aleatoria de 160 bits y la muestra una sola vez. Guárdala en tu gestor de contraseñas: es lo único que necesitas para entrar desde cualquier dispositivo.
  3. Si la pierdes, genera un código nuevo con npx create-orqevio@latest recover (Cloudflare) o docker compose exec app node dist/cli.js reset-access (Docker), y úsalo en «¿Has perdido la clave?». Tu bóveda no se ve afectada: su contraseña maestra nunca la conoce el servidor.

Tu copia usa el idioma de tu navegador al reclamarla: inglés, español, francés, portugués, italiano, alemán, neerlandés o japonés. Puedes cambiarlo cuando quieras en Ajustes.

Conectar agentes

La dirección MCP de tu copia es https://<tu-copia>/mcp.

  • Claude en la web, el escritorio y el móvil: añade un conector personalizado con esa dirección. Tu copia te pedirá permiso en una pantalla donde eliges el espacio y qué puede hacer. Tu copia tiene que ser accesible por HTTPS desde Internet; en Cloudflare ya lo es.
  • Claude Code, Cursor, VS Code y otros: en Agentes → Conectar un agente creas un token y la app te da la configuración para pegar.

Ningún agente puede leer la bóveda, ni siquiera cifrada, y ninguno puede borrar: solo archivar, y tú puedes restaurar.

Actualizar

Tu copia te avisa en Ajustes → Esta copia cuando hay una versión nueva, con el paso exacto para tu instalación. Tus datos, tu clave y tu bóveda se conservan siempre.

InstalaciónCómo actualizar
Con un comandonpx create-orqevio@latest update
Con el botónFusiona el pull request de Dependabot en tu repositorio
Con Dockerdocker compose pull y docker compose up -d

Desinstalar

Ajustes → Desinstalar Orqevio lo borra todo para siempre: espacios, documentos, adjuntos, la bóveda y el acceso de tus agentes. Lo confirmas con tu clave de acceso y escribiendo el nombre de la copia. Después, la copia te explica cómo quitar lo que queda:

InstalaciónCómo quitar lo que queda
Con un comandonpx create-orqevio@latest uninstall borra el Worker y su bucket
Con el botónEl Worker y su bucket de R2, en el panel de Cloudflare; después, el repositorio que creó el botón
Con Dockerdocker compose down -v y, después, la carpeta donde la instalaste

Orqevio no cuesta nada. Con Docker pagas tu servidor. En Cloudflare, el plan gratuito basta para uso personal:
