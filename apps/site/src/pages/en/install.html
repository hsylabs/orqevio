Install guide

Install your copy

Choose where it lives: in your Cloudflare account, with a command or a button, or on your server with Docker. In all three cases the copy is yours and works the same.

With a command Recommended

Your copy is installed in your own Cloudflare account: a Worker with the web app, the API and MCP, a SQLite database and an R2 bucket for attachments.

You need a Cloudflare account (the free plan is enough) and Node.js 22.12 or later.

Before you start, enable R2 in the Cloudflare dashboard, under R2 → Overview. The included usage is free (10 GB of storage a month), although Cloudflare may ask for a payment method. Both ways of installing on Cloudflare need it: the command and the button.

$ npx create-orqevio
  1. Your browser opens so you can sign in to Cloudflare.
  2. You pick a name for the copy (orqevio by default), which becomes part of its address.
  3. The installer deploys the copy and creates its bucket.
  4. It shows you the address (https://orqevio.<your-subdomain>.workers.dev) and a one-time setup code.

Open the address and follow the first sign-in.

  • Several copies: add --name <name> to any command.
  • Several Cloudflare accounts: the installer asks which one to use, or pass it with --account <id>.
  • If the browser doesn’t open to sign in, open the link the installer shows. If that doesn’t work either, sign in on its own with npx wrangler login --browser=false and run the installer again.
  • Language: the installer speaks your terminal’s language; choose another with --lang <code>.
  • Privacy: the installer turns off Wrangler’s telemetry, unless you turned it on yourself, and works in a temporary folder that it deletes when it finishes.

With the button

If you’d rather keep your copy in a repository of your own on GitHub or GitLab:

Deploy to Cloudflare

Cloudflare creates a small repository in your GitHub or GitLab account, asks you for the setup code (SETUP_CODE), which you choose, and deploys the copy. After that:

  • Every change to that repository is deployed automatically.
  • Dependabot proposes new versions of Orqevio in a pull request; merging it updates your copy.
  • If you lose your key, change the SETUP_CODE secret in the Cloudflare dashboard and use “Lost your key?” on the sign-in screen.

With Docker on your server

A single container (for amd64 and arm64) with its SQLite database and attachments in a volume. Download the configuration:

$ curl -fsSLO https://raw.githubusercontent.com/hsylabs/orqevio/main/docker-compose.yml
$ curl -fsSL -o .env https://raw.githubusercontent.com/hsylabs/orqevio/main/.env.example

Edit .env: set APP_URL to your copy’s public address (for example, https://orqevio.your-domain.com) and, if you like, a SETUP_CODE of your own with at least 12 letters or digits. Then:

$ docker compose up -d

The copy listens on port 3000. Put it behind a reverse proxy with HTTPS (Caddy, Nginx or Traefik) and add TRUST_PROXY=true to .env.

Backups: copy the orqevio-data volume while the copy is stopped, or make a live backup of the database with sqlite3 and also keep the uploads folder.

First sign-in

  1. Claim your copy. Open its address and enter the setup code and your name. On Cloudflare the installer gives it to you; with Docker, it’s the SETUP_CODE in .env or, if you didn’t set one, the one in the container log (docker compose logs app).
  2. Save your access key. Orqevio generates a random 160-bit key and shows it only once. Save it in your password manager: it’s all you need to sign in from any device.
  3. If you lose it, generate a new code with npx create-orqevio@latest recover (Cloudflare) or docker compose exec app node dist/cli.js reset-access (Docker), and use it in “Lost your key?”. Your vault isn’t affected: the server never knows its master password.

Your copy speaks the language your browser uses when you claim it, in English, Spanish, French, Portuguese, Italian, German, Dutch or Japanese. You can change it at any time in Settings.

Connect agents

Your copy’s MCP address is https://<your-copy>/mcp.

  • Claude on the web, desktop and mobile: add a custom connector with that address. Your copy asks for your permission on a screen where you choose the workspace and what it can do. Your copy has to be reachable over HTTPS from the internet; on Cloudflare it already is.
  • Claude Code, Cursor, VS Code and others: in Agents → Connect an agent you create a token and the app gives you the configuration to paste.

No agent can read the vault, not even encrypted, and none can delete: they can only archive, and you can restore.

Update

Your copy tells you in Settings → This copy when there’s a new version, with the exact step for your installation. Your data, your key and your vault are always kept.

InstallationHow to update
With a commandnpx create-orqevio@latest update
With the buttonMerge the Dependabot pull request in your repository
With Dockerdocker compose pull and docker compose up -d

Uninstall

Settings → Uninstall Orqevio deletes everything for good: workspaces, documents, attachments, the vault and your agents’ access. You confirm with your access key and by typing the copy’s name. Then the copy shows how to remove what’s left:

InstallationHow to remove the rest
With a commandnpx create-orqevio@latest uninstall deletes the Worker and its bucket. It can also do everything in one step, without going through Settings: it asks for your access key to empty the copy first
With the buttonThe Worker and its R2 bucket, in the Cloudflare dashboard; then the repository the button created
With Dockerdocker compose down -v, then the folder where you installed it

Costs

Orqevio costs nothing. With Docker you pay for your server. On Cloudflare, the free plan is enough for personal use:
