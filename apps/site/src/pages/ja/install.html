Orqevioをインストール

動かす場所を選べます。Cloudflareアカウントにコマンドかボタンでインストールするか、Dockerで自分のサーバーに置くかです。どの方法でも、Orqevioはあなた専用で、同じように動きます。

コマンドで おすすめ

Orqevioは、あなた自身のCloudflareアカウントにインストールされます。構成は、Webアプリ・API・MCPを提供するWorker、SQLiteデータベース、添付ファイル用のR2バケットです。

必要なもの：Cloudflareアカウント（無料プランで十分です）と、Node.js 22.12以降。

始める前に、R2を有効にしてください。CloudflareのダッシュボードのR2 → Overviewで有効にできます。無料枠（ストレージは月10 GBまで）なら料金はかかりませんが、Cloudflareから支払い方法の登録を求められることがあります。Cloudflareへのインストールには、コマンドとボタンのどちらの方法でもR2が必要です。

$ npx create-orqevio
  1. ブラウザが開くので、Cloudflareにログインします。
  2. Orqevioの名前を決めます（既定はorqevio）。名前はアドレスの一部になります。
  3. インストーラーがOrqevioをデプロイし、バケットを作成します。
  4. アドレス（https://orqevio.<サブドメイン>.workers.dev）と、1回限りのセットアップコードが表示されます。

アドレスを開き、初回ログインに進んでください。

  • 複数のOrqevio：どのコマンドにも--name <名前>を付けられます。
  • 複数のCloudflareアカウント：どのアカウントを使うか、インストーラーが尋ねます。--account <id>で指定することもできます。
  • ログイン用のブラウザが開かない場合：インストーラーが表示するリンクを開いてください。それでもうまくいかない場合は、npx wrangler login --browser=falseで別途ログインしてから、インストーラーをもう一度実行してください。
  • 言語：インストーラーはターミナルの言語で表示されます。別の言語にするには--lang <コード>を指定します。
  • プライバシー：インストーラーはWranglerのテレメトリーを無効にします（自分で有効にしている場合を除きます）。作業は一時フォルダーで行い、終了時にそのフォルダーを削除します。

ボタンで

GitHubやGitLabの自分のリポジトリでOrqevioを管理したい場合は、こちらのボタンを使います：

Deploy to Cloudflare

CloudflareがGitHubまたはGitLabのアカウントに小さなリポジトリを作成し、セットアップコード（SETUP_CODE）を尋ねたうえで、Orqevioをデプロイします。コードは自分で決めます。その後は：

  • そのリポジトリへの変更は、すべて自動でデプロイされます。
  • Orqevioの新しいバージョンはDependabotがプルリクエストで提案し、マージするとOrqevioが更新されます。
  • キーを紛失したら、CloudflareのダッシュボードでシークレットSETUP_CODEを変更し、ログイン画面の「キーを紛失した場合」を使います。

Dockerで自分のサーバーに

コンテナは1つだけ（amd64とarm64に対応）。SQLiteデータベースと添付ファイルはボリュームに保存されます。まず設定ファイルをダウンロードします：

$ curl -fsSLO https://raw.githubusercontent.com/hsylabs/orqevio/main/docker-compose.yml
$ curl -fsSL -o .env https://raw.githubusercontent.com/hsylabs/orqevio/main/.env.example

.envを編集し、APP_URLにOrqevioの公開アドレス（例：https://orqevio.example.jp）を設定します。必要なら、英字または数字12文字以上で独自のSETUP_CODEも設定できます。その後：

$ docker compose up -d

Orqevioはポート3000で待ち受けます。HTTPS対応のリバースプロキシ（Caddy、Nginx、Traefik）の背後に置き、.envにTRUST_PROXY=trueを追加してください。

バックアップ：Orqevioを停止した状態でorqevio-dataボリュームをコピーするか、sqlite3で稼働中のデータベースをバックアップし、uploadsフォルダーも保存してください。

初回ログイン

  1. Orqevioをセットアップします。アドレスを開き、セットアップコードと名前を入力します。Cloudflareでは、コードはインストーラーが表示します。Dockerでは.envのSETUP_CODEで、設定していない場合はコンテナのログ（docker compose logs app）に表示されるコードです。
  2. アクセスキーを保存します。Orqevioがランダムな160ビットのキーを生成し、一度だけ表示します。パスワードマネージャーに保存してください。どのデバイスからでも、このキーだけでログインできます。
  3. キーを紛失したら、npx create-orqevio@latest recover（Cloudflare）またはdocker compose exec app node dist/cli.js reset-access（Docker）で新しいコードを生成し、「キーを紛失した場合」で入力します。保管庫には影響しません。サーバーがマスターパスワードを知ることはないからです。

Orqevioは、セットアップしたときのブラウザの言語で表示されます。対応言語は英語、スペイン語、フランス語、ポルトガル語、イタリア語、ドイツ語、オランダ語、日本語で、設定からいつでも変更できます。

エージェントの接続

OrqevioのMCPアドレスはhttps://<あなたのOrqevio>/mcpです。

  • Claude（Web、デスクトップ、モバイル）：このアドレスでカスタムコネクタを追加します。Orqevioに許可を求める画面が表示されるので、ワークスペースと許可する操作を選びます。OrqevioにはインターネットからHTTPSでアクセスできる必要がありますが、Cloudflareなら最初からその状態です。
  • Claude Code、Cursor、VS Codeなど：エージェント → エージェントを接続でトークンを作成すると、貼り付ける設定がアプリに表示されます。

どのエージェントも保管庫は読めません。暗号化された状態でも同じです。削除もできず、できるのはアーカイブだけで、あなたが復元できます。

更新

新しいバージョンが出ると、設定 → このOrqevioに、インストール方法に合った手順とともに表示されます。データ、キー、保管庫は常にそのまま保持されます。

インストール方法更新方法
コマンドでnpx create-orqevio@latest update
ボタンでリポジトリでDependabotのプルリクエストをマージ
Dockerでdocker compose pullのあとにdocker compose up -d

アンインストール

設定 → Orqevioのアンインストールで、ワークスペース、ドキュメント、添付ファイル、保管庫、エージェントのアクセスをすべて完全に削除します。アクセスキーとOrqevioの名前を入力して確定します。その後、残りを削除する方法が表示されます：

インストール方法残りの削除方法
コマンドでnpx create-orqevio@latest uninstallでWorkerとバケットを削除
ボタンでCloudflareのダッシュボードでWorkerとR2バケットを削除し、ボタンが作成したリポジトリも削除
Dockerでdocker compose down -vのあと、インストールしたフォルダーを削除

費用

Orqevio自体は無料です。Dockerの場合はサーバーの費用がかかります。Cloudflareなら、個人で使うには無料プランで十分です：

リソース無料プラン
リクエスト1日あたり100,000件
CPUリクエストあたり10 ms（通常の使い方なら1〜5 msに収まります）
データベースOrqevio 1つにつき1 GB
添付ファイル（R2）月10 GB、書き込み100万回

2026年11月時点の制限です。最新の制限はCloudflareのドキュメントで確認してください。
